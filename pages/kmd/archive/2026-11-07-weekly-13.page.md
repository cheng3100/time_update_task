# GPU KMD Weekly #13

**日期：2026-11-07**  
**定位：Memory / UVM Owner 技术周报**

## 本期重点

### AMDGPU：TLB invalidation completion 正式进入 BO lifetime

PTE 已删除并不意味着 GPU 已无法使用旧 translation。AMDGPU v2 通过 `vm->last_tlb_inv` 把 TLB invalidation completion 连接到 BO reservation/lifetime。

- https://mail-archive.com/amd-gfx%40lists.freedesktop.org/msg155047.html

### DMA-BUF：从固定 `sg_table` 向 Mapping Type negotiation 演进

Mapping Types v2/23 开始允许 importer/exporter 协商双方能够理解的 mapping representation，为 VRAM、P2P、IOMMUFD 等场景扩展传统 dma-buf 模型。

- https://lists.openwall.net/netdev/2026/11/05/140

## A. L3/L4 Key Topic List

### A1. L4 · Memory/UVM — TLB invalidation completion 与 BO lifetime

AMDGPU 修复 GPUVA unmap 与 GEM object close 之间的 lifetime race，使 translation-cache completion 成为 BO lifetime dependency。

- https://mail-archive.com/amd-gfx%40lists.freedesktop.org/msg155047.html
- [Focus →]({{ '/kmd_owner_direction/memory/focus/2026-11-07-tlb-bo-lifetime/' | relative_url }})

### A2. L3 · DMA-BUF — Mapping Types v2/23

传统 `sg_table + dma_addr_t` 难以覆盖 VRAM、P2P、IOMMUFD 等不同 address semantics；Mapping Types 引入 mapping representation negotiation。

- https://lists.openwall.net/netdev/2026/11/05/140
- [Focus →]({{ '/kmd_owner_direction/memory/focus/2026-11-07-dmabuf-mapping-types/' | relative_url }})

### A3. L3 · PCIe P2P — Topology reachable ≠ DMA addressable

Topology 可达不等于 importer DMA mask 能覆盖 exporter VRAM BAR；P2P capability 需要独立考虑 addressability。

- https://lists.openwall.net/linux-kernel/2026/11/04/194
- [Focus →]({{ '/kmd_owner_direction/memory/focus/2026-11-07-pcie-p2p-addressability/' | relative_url }})
