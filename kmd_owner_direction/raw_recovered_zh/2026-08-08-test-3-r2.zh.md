## 保持不变的技术结论

1. Memory：recoverable fault + HMM + migration + replay，并保留 migration granularity 与 N:1 multi-device compatibility。
2. Firmware：versioned async protocol + capability negotiation + restart/state reconciliation；firmware-version independence 是核心 invariant。
3. RAS：destructive recovery 前保存 snapshot/devcoredump + FW logs + reset reason。
4. Multi-GPU：shared VM 之前先完成 stable identity/topology/P2P capability。
5. Observability：stable event/object identity + eBPF trace，PMU 后续加入同一 timeline。
6. Virtualization：SR-IOV 继续由 ASIC capability gate；重点是 GPU resource provisioning/isolation，而不是 generic PCI enable API。
7. Power：reusable telemetry first，复杂 governor later。
