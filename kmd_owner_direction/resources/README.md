# KMD Long-term Learning Resource Library

This library is intentionally separate from per-run Industry Updates.

- **Industry Updates** are fresh signals, grouped by top-level Owner and refreshed every run.
- **Learning Resources** are stable, high-value references grouped by long-term sub-direction and changed only when a clearly better reference appears.

Owner libraries:
- [Memory](memory.md)
- [Virtualization / Security](virtualization_security.md)
- [Power / Performance](power_performance.md)
- [Reliability / Recovery / RAS](reliability_ras.md)
- [Multi-GPU / P2P / Fabric](multi_gpu_fabric.md)
- [Observability / Profiling](observability_profiling.md)
- [Firmware / Control Plane](firmware_control_plane.md)
