## Detailed feature of this run
**Recoverable GPU Fault Service Contract**

Key correctness model:
```text
fault packet
→ PASID/VM/context lookup
→ validate VM/context/reset generation
→ HMM/MMU-notifier-sequenced CPU PTE state
→ map/migrate residency
→ GPU PTE
→ TLB invalidate
→ revalidate generation
→ replay or terminate
```

Required race matrix: fault vs `munmap`, `mprotect`, COW, process exit, VM/context destroy, migration completion, and GPU/FW reset.

First 3–6 month deliverable: one end-to-end pageable-memory path with trace IDs, migration, PTE/TLB/replay ordering and fault-injection tests. Expansion: batched faults, large/compound migration, oversubscription/eviction, then N:1 multi-device metadata.
